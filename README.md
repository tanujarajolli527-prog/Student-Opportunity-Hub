# Student Opportunity Hub 🎓

Welcome to the **Student Opportunity Hub**, a modern, lightweight, and responsive web platform designed to help students discover verified global opportunities ranging from internships and scholarships to hackathons and free educational courses.

---

## 🚀 Features

- **Rich Opportunity Listings**: Over 30+ curated and verified items across four major categories:
  - 💼 **Internships**: Top global tech companies and research programs.
  - 🎓 **Scholarships**: Financial aid and global fellowship grants.
  - ⚡ **Hackathons**: National and international coding challenges.
  - 📚 **Free Courses**: World-class computer science and tech curriculums.
- **Smooth Navigation**: Fixed glassmorphism navigation bar with quick anchor scrolling.
- **Professional Creator Section ("About Me")**: Highlights the developer with direct interactive links to professional networks.
- **Pure HTML & CSS Architecture**: Lightweight design built entirely without complex frameworks or heavy JavaScript dependencies for maximum performance and speed.

---

## 📂 Tech Stack

- **HTML5**: Structured semantic layout for all opportunity categories.
- **CSS3**: Modern styling featuring Flexbox, CSS Grid, Glassmorphism, smooth scrolling, and a professional dark SaaS color palette.
- **FontAwesome**: Icons for professional social and navigation links.
